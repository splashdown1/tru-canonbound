# TRU — Canonbound

Offline, non-LLM, **canon-bound** scripture engine. One self-contained HTML file (~31 MB). Zero network at runtime, zero telemetry.

**Run it:** open [the live page](https://splashdown1.github.io/tru-canonbound/TRU.html) in any browser, or download `TRU.html` and open it locally — it works identically with no internet.

## What it is
- **Deterministic lanes only** — every answer comes from a source-backed lookup, never generated text.
- **Honest GAP** — when no canon source matches, TRU says so instead of guessing or reframing your question into scripture.
- **The Socratic follow-up** — after each answer, one data-derived question assembled from the cross-references, root chains, or Nave's see-also of what was just answered. Always clickable, always answerable offline.
