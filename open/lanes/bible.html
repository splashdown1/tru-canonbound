What it is

TRU is a single HTML file that is an entire Bible word-study engine. The KJV, a Strong's-number lexicon, cross-references, two topical textbooks and a doctrinal phrase map are embedded inside it. Open the file anywhere — phone, laptop, airplane — and it runs. It makes no network calls. Every answer traces back to an embedded source, and when a source is silent, TRU says so with a clean GAP rather than inventing content.

How answers are grounded

Single words → LOGOS Lexicon

Every Greek/Hebrew entry with lemma, transliteration, definition, KJV usage counts, root and part of speech. Scored routing picks the right entry; "grace" lands on χαρις G5485, not look-alikes.

Doctrinal phrases → Strong's pairs

521 curated and auto-mined phrases: "eternal life" → G2222 + G166; "faith without works" → G4102 + G2041. Every Strong's ID is verified present in the lexicon.

Topics → Nave's + Torrey's

Nave's Topical Bible (1897) and Torrey's Topical Textbook, audited build with zero unresolved scripture references. "access to God" → Torrey's verse groups.

Phrases → KJV text

Exact multi-word search across all 31,100 verses, with in-order token matching as fallback. "judge not that ye be judged" → Matthew 7:1, quoted verbatim.

Verses → KJV + TSK

Any "book chapter:verse" reference returns the KJV text with Treasury of Scripture Knowledge cross-references, plus a built-in speech reader that reads the Bible aloud.

Local memory

Teach it facts with remember: … and recall them later with recall: …. Memory stays in your browser, offline.

The honesty rules

  • No invention. Every claim is quoted or cited from an embedded source. No network, no AI generation.
  • GAP is an answer. Non-biblical words ("indifference", "insomniac") return a clean gap — the UI states exactly what lookups are and are not supported.
  • Deterministic. The same question always returns the same answer. Routing is inspectable in the file's source.
  • Scope, stated. This is a word-study and verse-reference companion, not a doctrinal authority. It assembles what the sources say; it does not interpret them.
